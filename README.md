# AI 自走車常態班 報名網站｜設定說明

## 資料夾內容

| 檔案 | 用途 |
|---|---|
| `index.html` | 報名網站本體（單一檔案，直接上傳即可） |
| `img/` | 網站圖片（微研 LOGO、課堂實況照片、傳單） |
| `story.html` | 世界觀頁《曙城重啟》：故事、地圖、角色、故障生物圖鑑、站章與駕照 |
| `img/story/` | 世界觀用圖：3 張 AI 場景插圖（city／hangar／storm）、角色頭像、15 隻故障生物、8 枚站章（SVG） |
| `google-apps-script/Code.gs` | 接收報名資料、寫入 Google 試算表的程式 |

## 一、接上 Google 試算表（約 5 分鐘，只需做一次）

1. 到 Google 雲端硬碟新增一份試算表，例如命名「AI 自走車常態班 報名資料」。
2. 試算表上方選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，把 `google-apps-script/Code.gs` 全部內容貼上，按 💾 儲存。
   - 想要「有人報名就寄信通知」：把 `NOTIFY_EMAIL = ''` 改成你的信箱。
4. 右上角 **部署 → 新增部署作業**：
   - 類型選「**網頁應用程式**」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按「部署」→ 依指示授權（會出現「Google 尚未驗證這個應用程式」→ 進階 → 前往（不安全）→ 允許；這是你自己的程式，屬正常流程）。
6. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
   **先把這個網址貼到瀏覽器打開**，看到「AI 自走車常態班報名接收程式運作中」才代表部署成功。
   （重要：網站送出時無法得知試算表端是否出錯，網址貼錯也會顯示「報名成功」，所以這一步一定要確認。）
7. 打開 `index.html`，搜尋 `SHEET_WEBHOOK_URL: ''`，把網址貼進引號中：
   ```js
   SHEET_WEBHOOK_URL: 'https://script.google.com/macros/s/……/exec',
   ```
8. 測試：在網站送出一筆報名 → 試算表會自動出現「報名資料」分頁和一列資料。

> 早鳥價由試算表端用 Google 伺服器時間重新判斷，訪客改電腦時間也拿不到早鳥價。
> 若要改截止日或價格，網站 `CONFIG` 與 Apps Script 開頭的 `EARLY_BIRD_DEADLINE`、`PRICE_*` 兩邊都要改。
>
> 之後如果修改 Apps Script 程式（包括填入 `NOTIFY_EMAIL` 開啟通知信，會多要求一次寄信授權），要用 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 重新部署，網址才會維持不變。

## 二、試算表欄位

收到時間｜報名編號｜報名類型（報名整期／試聽一堂）｜課程｜學生姓名｜年級｜就讀學校｜程式基礎｜家長姓名｜家長電話｜緊急聯絡人｜緊急聯絡電話｜付款方式｜應繳金額｜早鳥｜個資同意｜處理狀態（預設「待聯繫」）｜備註

「處理狀態」「備註」兩欄留給你手動更新（例如：已聯繫、已付款、已試聽）。

## 三、網站上可調整的設定（`index.html` 最下方 `CONFIG`）

| 設定 | 目前值 | 說明 |
|---|---|---|
| `EARLY_BIRD_DEADLINE` | 2026-11-30 23:59:59 | 早鳥截止；過了之後網站自動改顯示原價、隱藏倒數 |
| `PRICE_ORIGINAL` | 4800 | 原價 |
| `PRICE_EARLY` | 4200 | 早鳥價 |
